Claude 浏览器地区自检

Vibe coding 项目 · 请在实际使用 Claude 的浏览器配置中打开；不同配置的结果可能不同。基本检查仅在本机运行，结果不会上传。WebRTC 按钮会向配置的公共 STUN 服务器发送诊断连接。

  1. 开启自己的代理，确认目标出口国家，再用 Claude 所在浏览器打开本页面。
  2. 查看下方时区、网页首选语言和请求头；预设目标为日本，可通过项目配置调整。
  3. 运行 WebRTC 检查，查看候选地址；在同一浏览器打开 Claude 出口检查，核对 loc=JP。
  4. 保存 JSON，修改设置后再检查并比较。
